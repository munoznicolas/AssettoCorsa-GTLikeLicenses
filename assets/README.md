# Media Assets Catalog (`assets/`)

## Overview
This directory contains static audio samples, UI textures, career badge art, and TrueType fonts.

---

## Subdirectories
```
assets/
├── audio/                       # 16-bit 44.1kHz PCM mono WAV files
│   ├── countdown_beep.wav       # 880Hz electronic countdown beep
│   ├── countdown_go.wav         # 1760Hz GO chime
│   ├── fail_buzzer.wav          # Acoustic beat-frequency fail buzzer
│   ├── pass_fanfare.wav         # Triad pass fanfare
│   └── gold_fanfare.wav         # Ascending victory fanfare
├── textures/                    # 32-bit RGBA PNG graphics
│   ├── medal_gold.png           # Gold laurel icon
│   ├── medal_silver.png         # Silver laurel icon
│   ├── medal_bronze.png         # Bronze laurel icon
│   ├── ribbon_start.png         # Start gate ribbon texture
│   └── ribbon_finish.png        # Finish gate chequered flag ribbon
├── career_ui/                   # High-res series badge banners for Content Manager
│   ├── series_b_badge.png
│   ├── series_a_badge.png
│   ├── series_ib_badge.png
│   ├── series_ia_badge.png
│   └── series_s_badge.png
└── fonts/                       # Single source of truth TrueType typography for CSP DirectWrite
    ├── arkitech_bold.ttf
    ├── arkitech_light.ttf
    ├── arkitech_medium.ttf
    ├── gt7-MyFont Black.ttf
    ├── gt7-MyFont Bold.ttf
    ├── gt7-MyFont Light.ttf
    ├── gt7-MyFont Medium.ttf
    ├── gt7-MyFont Regular.ttf
    ├── gt7-MyTimingFont.ttf
    └── gt7-MyTimingFontOutline.ttf
```
